# 단위 변환기 웹앱 (Unit Converter Web App)

이 프로젝트는 웹 브라우저에서 바로 실행할 수 있는 간단하고 직관적인 **단위 변환기** 프로그램입니다. HTML, CSS, JavaScript를 각각의 파일로 분리하여 웹 표준을 준수하고 유지보수하기 쉽게 구성되었습니다.

## 🌟 주요 기능

- **실시간 변환:** 값을 입력하거나 단위를 변경할 때마다 즉시 변환된 결과를 보여줍니다.
- **카테고리 분류:** '길이(Length)'와 '무게(Weight)' 두 가지 변환 모드를 지원합니다.
- **직관적인 UI:** 깔끔하고 모던한 카드형 디자인과 부드러운 인터랙션을 제공합니다.
- **확장성:** 새로운 단위나 카테고리를 쉽게 추가할 수 있는 구조로 작성되었습니다.

## 📁 프로젝트 구조

프로젝트는 역할에 따라 세 개의 파일로 나누어져 있습니다:

- `index.html`: 웹앱의 뼈대와 구조(DOM)를 정의합니다.
- `style.css`: 레이아웃, 색상, 폰트 등 시각적인 디자인 요소를 정의합니다.
- `script.js`: 단위 변환 계산 로직과 사용자 상호작용(이벤트 처리)을 담당합니다.

## 🚀 실행 방법

1. 프로젝트 폴더에 `index.html`, `style.css`, `script.js` 세 개의 파일을 같은 위치에 저장합니다.
2. `index.html` 파일을 더블클릭하여 웹 브라우저(Chrome, Safari, Edge 등)에서 엽니다.
3. 별도의 서버 설치나 구성 없이 바로 사용할 수 있습니다.

## 🛠 커스터마이징 (단위 추가하기)

새로운 단위를 추가하고 싶다면 `script.js` 파일을 열고 다음 두 가지 객체를 수정하세요.

1. **`unitsData`**: 새로운 단위의 변환 비율을 추가합니다. (길이는 `m`, 무게는 `kg` 기준)
2. **`unitLabels`**: 화면에 표시될 단위의 이름(텍스트)을 추가합니다.

**예시 (길이 단위 '야드(yd)' 추가하기):**
```javascript
const unitsData = {
    length: {
        'm': 1,
        // ... 기존 코드 ...
        'yd': 1.09361 // 미터(m) 기준 야드(yd) 비율 추가
    }
};

const unitLabels = {
    // ... 기존 코드 ...
    'yd': '야드 (yd)' // 표시될 이름 추가
};
```
